| 정답지 보고 규칙을 고쳤으면 당연히 좋아지는 거 아냐? | 고친 건 pastry, dough 같은 일반 밀 재료 이름. "오류 분석으로 찾았다"로 설명 |
| 한식은? | 레시피가 30개 미만이라 "정보 부족"으로 표시 → 개선 과제 |
| 경고가 너무 많아지지 않나? | 항상 합치면 괜한 주의 8.4%, 우리 방식 1.3% |
