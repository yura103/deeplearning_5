# evaluation — 알레르기 정답지 (담당: 서준영)

**상태: 확인 완료** (서준영, 2026-11-17). 레시피 84개를 전부 열어 확인했고 틀린 곳은 없었다.

초안은 AI 도구로 레시피를 찾고 재료를 표시해 만들었다. 그다음 **사람이 링크를 열어 전부 확인했다.**
(② 실험이 "LLM 판정"을 채점하므로, LLM이 만든 표를 확인 없이 쓰면 채점이 공정하지 않다.)
나중에 레시피 기록을 고치면 아래 "사람 확인 순서"대로 고친 음식을 다시 확인하고 이 줄을 바꾼다.

## 왜 만드나
앱은 레시피 통계 + 룰로 🔴주의 / 🟡확인 필요 / ⚪해당 없음을 낸다. 이게 맞는지 채점하려면 **사람이 확인한 정답**이 있어야 한다.

| 쓰는 곳 (`docs/역할분담.md` 서준영) | 무엇을 재나 |
|---|---|
| ② 룰 판정 vs LLM 직접 판정 | 위험한 걸 몇 번 놓쳤나(FN). 진행상황 문서의 "가장 강한 증거" |
| ③ 1등만 vs 후보 3개 합치기 (`judge.merge`) | 합치기가 FN을 줄이나, FP는 얼마나 느나 |
| (나중에) 2단계 CLIP 검색 | 처음 보는 음식 판정 채점. 새 음식 후보 6종을 미리 넣어 둠 |

정답지가 시스템을 닮으면 채점이 의미 없다. 그래서 **따로** 만들었다.
- 우리 데이터(1M_Final)가 아니라 **외부 레시피 사이트**의 레시피 3개로 정했다.
- `knowledge/food_table.csv`의 알레르기 비율은 **보지 않고** 만들었다. 음식을 고를 때 레시피 수만 봤다.

## 음식 28종
- **Food-101 22종** (③은 Food-101 시험 사진이 필요): pad_thai, ramen, pho, gyoza, fried_rice, pizza, spaghetti_carbonara, spaghetti_bolognese, caesar_salad, pancakes, tiramisu, carrot_cake, baklava, risotto, clam_chowder, paella, crab_cakes, fried_calamari, shrimp_and_grits, french_onion_soup, chicken_curry, mussels
- **새 음식 후보 6종** (2단계용): satay, soba, teriyaki_chicken, tempura, mapo_tofu, bulgogi
- 모두 `food_table.csv`에 있고 레시피 30개 이상이다. `정보 부족`이 아니라 실제 판정이 나오는 음식들이다.
- "안 보이는 재료"가 있는 음식 위주로 골랐다. 간장 속 밀(데리야키·불고기), 소스 속 땅콩(사테), 육수 속 닭고기(리조또), 와인 속 아황산류(볼로네제·양파수프).
- 헷갈리기 쉬운 짝도 넣었다. 라멘(밀 1) ↔ 쌀국수(밀 0). `judge.py` 자체 검사에 나오는 예와 같다.
- 19항목 중 16항목은 정답 1인 음식이 있다. **고등어·복숭아·잣은 175종 표에 대표 음식이 없어 0개**다. 이 3항목은 FN을 잴 수 없고 FP만 잴 수 있다.

## "들어감" 기준
1. 음식마다 레시피 3개 (아래 고르는 법).
2. 레시피 재료 목록에 그 항목이나 그걸로 만든 재료가 있으면, 그 레시피는 "있음".
3. **3개 중 2개 이상 → 1.** 1개만 → 0 (`정답지_근거.md`에 "경계"로 표시). 0개 → 0.

앱 판정은 레시피 비율 60% 이상이 `주의`, 20% 이상이 `확인 필요`다. 정답 1("대부분 들어감")은 `주의`와 맞닿는다. 경계 칸은 `확인 필요`가 자연스러운 자리다.

### 레시피 고르는 법 (원하는 레시피만 골라 쓰지 않도록 미리 정함)
| 음식 | R1 | R2 | R3 |
|---|---|---|---|
| 아시아 음식 | 그 나라 음식 전문 사이트 (일본 Just One Cookbook, 중국 The Woks of Life, 태국 Hot Thai Kitchen, 한국 Maangchi, 그 밖 RecipeTin Eats) | Food Network | Taste of Home |
| 그 밖 | Food Network | Taste of Home | RecipeTin Eats |

- 그 사이트에 레시피가 없으면 Food.com.
- 사이트 안에서 음식 이름으로 검색한다. **제목이 음식 이름과 같은 첫 레시피**를 고르고("Ina's ~"처럼 사람 이름 붙은 것 포함), 없으면 첫 번째 기본형을 고른다.
- 건너뛰는 것: 채식·비건·글루텐프리 같은 식단 변형, 다른 요리 형태(샐러드·볶음·캐서롤·시트팬 등), 반죽만 있는 레시피, 다른 레시피를 그대로 옮긴 것(재료 목록이 같음).
- 실제로 바꾼 곳:
  - pad_thai·satay R1: Hot Thai Kitchen이 자동 읽기를 막음 → RecipeTin Eats
  - bulgogi R1: Maangchi가 자동 읽기를 막음 → RecipeTin Eats
  - pizza R3: Food.com 첫 결과가 반죽만 있음 → 다음 "Pizza"
  - risotto R3: Food.com 첫 결과가 R1(Food Network)과 재료가 똑같음 → 다음 "Risotto"
  - fried_calamari R2·R3: Taste of Home·RecipeTin Eats에 없음 → Food.com 2개 (첫 결과는 R1과 같은 레시피라 건너뜀)
  - mussels R2: Taste of Home에 없음 → Food.com (첫 결과는 R1과 같은 레시피라 건너뜀)

### 재료 → 항목 읽는 법
| 재료 | 항목 |
|---|---|
| 간장 (soy sauce, dark·sweet soy sauce, 멘쓰유) | 대두 + 밀 |
| 미소, 두부, 에다마메, 발효 검은콩 | 대두 |
| 두반장·토반장 (chili bean paste) | 밀 |
| 고추장 | 대두 + 밀 |
| 굴소스 | 조개류(굴) + 밀 |
| 태국 레드·그린 커리 페이스트 | 새우 (새우 페이스트가 들어감) |
| 사오싱주 | 밀 |
| 소바면 | 메밀 + 밀 (보통 밀가루를 섞음) |
| 밀가루, 빵, 빵가루, 크루통, 파스타, 라멘·밀국수, 만두피, 필로 | 밀 |
| 레이디핑거 | 밀 + 알류 |
| 쌀국수, 쌀가루, 옥수수·감자 전분 | 해당 없음 |
| 달걀, 마요네즈 | 알류 |
| 버터, 치즈, 크림, 우유, 마스카포네, half-and-half | 우유 (코코넛밀크·아몬드밀크는 아님) |
| 베이컨, 햄, 판체타, 관찰레, salt pork, 라드, 초리조, 돼지 소시지, 차슈 | 돼지고기 |
| 닭 육수·부용 | 닭고기 |
| 소 육수·부용, 송아지(veal) | 쇠고기 |
| 토마토, 토마토소스·페이스트, 마리나라, 병 스파게티 소스 | 토마토 |
| 와인(화이트·레드), 셰리, 포트, 마르살라, 베르무트 | 아황산류 |
| 럼, 브랜디, 사케, 미림, 와인식초 | 해당 없음 |
| 앤초비, 피시소스, 가쓰오부시(가다랑어), 틸라피아 | 해당 없음 (고등어 아님) |
| 홍합, 조개, clam juice | 조개류 |

- "A or B"는 A만 본다.
- optional, serving suggestion, for the table(먹는 사람이 골라 넣는 소스)은 뺀다. 재료 목록에 그냥 적힌 고명·곁들임(garnish, to serve)은 넣는다.
- 식용유는 종류(땅콩기름 등)와 관계없이 넣지 않는다.
- 종류가 안 적힌 재료("chopped nuts", "broth")와 채식용 대체품(vegetarian chicken soup mix)은 넣지 않는다.

## 한계 (발표 때 같이 말할 것)
- 음식당 레시피 3개라 적다. 경계 칸은 레시피를 더 보면 바뀔 수 있다.
- 미국·호주 레시피 사이트 위주라 현지 식당과 다를 수 있다.
- 아황산류의 법 기준은 "완제품에 이산화황 10mg/kg 이상"이라 레시피로는 정확히 알 수 없다. 여기서는 와인류가 들어가면 1로 본 **보수적 기준**이다.
- 고등어·복숭아·잣은 정답 1인 음식이 없다.
- 레시피는 2026-11-17에 읽었다. 사이트가 레시피를 고치면 달라질 수 있다.

## 사람 확인 순서
1. `정답지_근거.md`를 열고 음식마다 링크 3개를 열어, 표에 적힌 재료가 레시피에 정말 있는지 본다. 위 "재료 → 항목 읽는 법"이 적용된 칸(간장→밀, 굴소스, 두반장, 커리 페이스트)을 특히 본다.
2. 틀린 곳은 `정답지_레시피기록.tsv`를 고치고 다시 실행한다.
3. 맨 위 상태를 "확인 완료 (이름, 날짜)"로 바꾼다.
